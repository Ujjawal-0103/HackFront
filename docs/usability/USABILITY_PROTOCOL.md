# Traceback Usability Testing Protocol & Evaluation Report

## 1. Overview & Context

This protocol defines the task-based usability evaluation for Traceback through Sprint 8. Traceback is a human-supervised code explanation verification system designed for software engineers maintaining established codebases.

### Testing Scope

- **Evaluation Target:** Complete end-to-end web workflow (`/`, `/register`, `/login`, `/repositories`, `/evidence`, `/verify`, `/history`).
- **Target Participants:** Professional software engineers, code reviewers, and tech leads maintaining non-trivial repositories.
- **Participant Status:** **EXTERNAL PARTICIPANT TESTING NOT YET COMPLETED** (Internal developer walkthrough conducted; external testing pending human participant recruitment in production/staging environment).

## 2. Usability Protocol: 8 Core Tasks

### Task 1: Create an Account and Sign In

- **Prompt:** "You are joining the engineering team. Navigate to the Traceback application, create an account using your email and a strong password, and sign in."
- **Success Criteria:** User successfully submits registration, is redirected or signs in, and reaches the authenticated dashboard/repositories view.
- **Expected Time:** < 90 seconds.

### Task 2: Connect or Select a Repository

- **Prompt:** "Select the primary repository `alpha/core-engine` from your authorized workspace. Check whether it is synchronized or trigger a sync."
- **Success Criteria:** User selects the repository, views the synchronization status or recent sync jobs, and understands whether indexing has completed.
- **Expected Time:** < 60 seconds.

### Task 3: Find Historical Evidence

- **Prompt:** "Search for past commits or PRs explaining why a cache lock was introduced into the caching system."
- **Success Criteria:** User navigates to `/evidence`, searches with query `cache lock`, applies the `COMMIT` filter, and views the canonical commit URL and code snippet provenance.
- **Expected Time:** < 90 seconds.

### Task 4: Verify a Code Explanation

- **Prompt:** "Paste an explanation from an AI coding assistant claiming: 'Cache lock was added to prevent concurrency defects during high-throughput background sync'. Request a verification."
- **Success Criteria:** User navigates to `/verify`, enters the explanation, clicks 'Verify Explanation', and views the extracted claims with preliminary machine confidence ratings.
- **Expected Time:** < 60 seconds.

### Task 5: Epistemological Understanding Check

- **Prompt:** "Inspect the resulting verification. What is the difference between the 'Machine Assessment' (e.g. HIGH_SUPPORT) and the 'Human Verdict' column?"
- **Success Criteria:** User verbally explains that the machine assessment is a statistical/heuristic citation match generated by Traceback, whereas the human verdict represents authoritative developer judgment.
- **Expected Time:** < 45 seconds.

### Task 6: Record and Revise a Human Verdict

- **Prompt:** "Record a human verdict of 'SUPPORTED' on the first claim, adding the note 'Confirmed in commit 7f8a9b1'. Then revise it to include an additional note."
- **Success Criteria:** User clicks verdict button, enters notes, saves. Then updates notes and confirms the revision appears in the persistent audit trail.
- **Expected Time:** < 90 seconds.

### Task 7: Reopen a Previously Saved Verification

- **Prompt:** "Simulate leaving your desk: close the session or return to History. Find the verification session you just worked on, reopen it, and confirm all claims and your recorded verdict are present."
- **Success Criteria:** User navigates to `/history`, locates the session by timestamp/explanation snippet, clicks through, and views all persisted state without data loss.
- **Expected Time:** < 60 seconds.

### Task 8: Export a Verification Report

- **Prompt:** "Export the verified explanation as a structured JSON report suitable for attaching to a pull request or compliance audit."
- **Success Criteria:** User clicks 'Export JSON Report', downloads or views the export, and verifies that it contains claim breakdown, source citations, and human verdicts without leaking internal credentials.
- **Expected Time:** < 45 seconds.
